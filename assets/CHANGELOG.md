## v1.3.1 · 2026-09-28

### 新增
- **图谱架构规范页（`standard.html`）新增「分层结构图」浮层**：第 1 章「总体架构」左侧六个分层名称变为可点击入口（含悬浮动效、键盘 Enter/Space 支持、"结构图 ↗"提示胶囊），点击后以浮层形式单独查看该层的结构图
- 每层结构图包含四块内容：**本层实体构成**（实体中文名 / Schema 类型 / 职责说明）、**关系链路**（按主题分 Tab，展示 `疾病 -[关系]-> 实体` 的完整走向）、**AMI 实例贯通**（以急性心肌梗死为例走通该层）、**硬规则**（该层不可违背的口径约束）
- 共 6 层 × 17 个主题 Tab × 54 条关系链路 × 142 个链路节点，纯静态数据、零接口依赖，离线可用；Esc 或点击浮层外空白处关闭
- 浮层采用独立配色（面板 `#0f1220` / 主色随层切换），不依赖站点主题变量，便于复用到方案与产品设计场景

### 修复
- **`app.js` 全局 Esc 监听空指针**：`closeModal()` 未判空导致非 `schema.html` 页面按 Esc 必报 `TypeError`（详见 `BUG_LOG.md` #015）

### 变更
- **本地仓库对齐线上 4001 整改状态**：14 个文件以线上为准回灌（导航、维度、统计口径）
- **作废文件彻底移除（12 个）**：`diagnosis.html`、`engine.html`、`disease.html` 等从仓库删除
- **`deploy.py` 新增 4 道保护闸**：黑名单 / 完整性 / 版本戳一致性 / 线上回归，杜绝"旧盖新"
- **维度口径统一为 20 个核心维度**（17 基础 + 3 护理），单一事实源改为 `/api/kg/dimensions`
- **统计口径双轨**：图谱实例数与 CDSS 字典映射数分区展示，不再混用
- **版本戳全站统一** `?v=2026092813`
- README.md、PROJECT_CONTEXT.md、部署清单 `.server-config.json` 全量重写对齐线上事实

## v1.3.0 · 2026-07-06

### 新增
- **诊断模拟指南来源展示**：匹配诊断结果卡片新增"诊疗指南依据"区域，推理有据可循
- **Redis 缓存层**：部署 Redis 7.0 到 `/zoesoft/zoekgRedis`，server.py 集成 `cache_get`/`cache_set`，API 响应提速
- **统计口径对齐 Codex 验收标准**：疾病大类 12、可视化实体 1,145、关系 99,269
- **统一版本管理**：`VERSION` 文件作为单一真相源，`/api/kg/version` API 接口，底部版本号自动跟随
- **全局缓存管理**：server.py 所有静态文件统一 `Cache-Control: no-cache` 策略

### 修复
- 默认疾病选择改为动态取第一个疾病大类下覆盖度最高的疾病（不再硬编码）
- 首页统计从 `dashboard.js` 累加计数改为 `app.js` 统一调用 `/api/kg/stats` API
- 所有 HTML 页面的 `app.js?v=xxx` 版本号问题彻底消除

### 数据
- 可视化实体：1,145（排除 Evidence 节点）
- 全库节点：34,292（含 Evidence 33,147）
- 关系：99,269（全类型）
